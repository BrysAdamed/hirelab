## User story

As a user, I want to file donation requests and have them processed, so that there is a history of every request and its outcome.

- When I file a request, it records who filed it, when, and the amount requested.
- When a request is processed, it records the decision and the date it was made. If the request is accepted, it also records the approved amount.

## Description

Added a controller with two endpoints to create and process requests.
